# CS2 External Radar

## Initial Idea

For our CS303 Project 4, we proposed creating a memory reader for Counter-Strike 2 (CS2) that displays information from the game in a graphical user interface (GUI).

The goal of our project is to read game data, such as player positions and other useful information, and display it in a simple and organized way.

We plan to use C++ to handle the memory reading and Dear ImGui to create the GUI. The program will take the information it reads and update the interface in real time.

This project will help us better understand memory management, working with external processes, and creating graphical interfaces using C++.
